.. _options-gif:

GIF output
==========

These options apply only when ``-m gif`` is selected.

.. program:: plopm

-gi/--gif-interval <MILLISECONDS>
---------------------------------

.. option:: -gi <MILLISECONDS>, --gif-interval <MILLISECONDS>
   :no-contents-entry:
   :no-typesetting:

Set the GIF frame interval in milliseconds.

**Default:** ``1000``

-gl/--gif-loop <0|1>
--------------------

.. option:: -gl <0|1>, --gif-loop <0|1>
   :no-contents-entry:
   :no-typesetting:

Loop GIF animations indefinitely when set to ``1``.

**Default:** ``0``
