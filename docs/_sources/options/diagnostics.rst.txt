.. _options-diagnostics:

Information and diagnostics
===========================

Inspect the variables available for an input case.

.. program:: plopm

-lv/--list-variables <0|1>
--------------------------

.. option:: -lv <0|1>, --list-variables <0|1>
   :no-contents-entry:
   :no-typesetting:

Print the available variables when set to ``1``.

**Default:** ``0``
